## Família Fit 2026.11.28 — atualizações sem reinstalar

### Descarregar
| Sistema | Como |
|---|---|
| **Windows** | `familia-fit-2026.11.28-instalador-windows.exe` (instalador — atualiza-se sozinho daqui em diante) ou `familia-fit-2026.11.28-portatil-windows.exe` (sem instalar) |
| **macOS** | `familia-fit-2026.11.28-mac-arm64.dmg` (Apple Silicon) ou `familia-fit-2026.11.28-mac-x64.dmg` (Intel) |
| **Linux** | `.AppImage` (atualiza-se sozinho daqui em diante) ou `.deb` |
| **Android** | Abre `https://hvs87.github.io/Familia-Fit/` no Chrome → menu → «Instalar app» |
| **iPhone e iPad** | Abre o mesmo endereço no Safari → Partilhar → «Adicionar ao ecrã principal» |
| **Web** | `familia-fit-2026.11.28-web.zip` |

**Esta é a última vez que é preciso instalar à mão.** A partir desta versão, a app atualiza-se sozinha. Instalar por cima da versão anterior mantém todos os dados.

Os instaladores de computador não são assinados:
- **Windows:** o SmartScreen pode avisar; carrega em «Mais informações» → «Executar mesmo assim».
- **macOS:** na primeira vez, clique direito → Abrir.

### Novo
- **Atualizações automáticas**, no telemóvel e no computador, sem reinstalar. Em Definições → Atualizações: o botão **«Procurar atualizações»** e a opção **«Procurar sempre atualizações ao iniciar»** (ligada por omissão). Quando há uma versão nova aparece um aviso e um ponto na roda dentada.
- **Os dados e as preferências ficam sempre.** No computador, antes de cada atualização fica uma cópia de segurança automática, e se a versão nova não arrancar o programa volta sozinho à anterior. Cada ficheiro descarregado é conferido pela impressão digital publicada.
- **O programa também se atualiza:** pelo instalador no Windows e pelo AppImage no Linux. No `.exe` portátil, no `.deb` e no macOS abre-se a página para descarregar.
- **Sincronização entre versões:** os dois aparelhos dizem um ao outro em que versão estão. Se o outro tiver uma mais recente, este procura-a logo. Um aparelho nunca aceita dados num formato que ainda não conhece: espera pela atualização em vez de perder informação.
